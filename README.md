C++ implementation of an endless runner game built with [raylib](https://www.raylib.com/). Run, jump, and dodge obstacles in a continuously generated world!

## ✨ Features
- **Procedurally generated levels:** Never run out of challenges with endless, dynamic obstacle generation.
- **High-performance gameplay:** Smooth, optimized rendering and input handling using raylib.
- **Clean and maintainable codebase:** Easily extendable C++ code.
- **Cross-platform compatibility:** Build and run on Windows, Linux, and macOS.

## 🚀 Getting Started

- **Clone the repository**:
  ```bash
  git clone https://github.com/yourusername/endless-runner.git

- **Open the project** in your favorite C++ IDE (e.g., Visual Studio Code, CLion, or Visual Studio).
- **Install raylib** following the official installation guide.
- **Configure your build system** (e.g., CMake) and compile the project.
- **Run the compiled binary** to launch the game.

## 🛠️ Usage

- **Game Launch:** Run the executable generated after building the project.
- **Controls:** Use the keyboard keys.
